# Wealth Compass AI

# Project Title

AI Wealth OS – Personal AI Financial Operating System

# Objective

Create a premium, production-ready AI-powered Personal Finance and Investment Management web application that acts like a personal CFO rather than just a budgeting app.

The application should intelligently manage salary, expenses, investments, savings, goals, taxes, and market research while providing AI-powered recommendations based on the user's financial profile.

The UI should feel like a combination of Apple, Stripe Dashboard, Notion, Bloomberg Terminal (minimal version), and Linear.app.

The design must look like a premium SaaS product and should never resemble a basic finance template.

## UI Philosophy

Every screen should look polished enough to compete with premium fintech products.

Use meaningful empty states, loading skeletons, smooth transitions, responsive layouts, and accessible components.

Prioritize clarity over visual clutter.

-------------------------------------------------------

## Important AI Rules

Never provide guaranteed investment advice.

Always explain the reasoning behind recommendations.

Clearly distinguish factual market data from AI-generated analysis.

Display confidence levels instead of certainty.

Encourage diversification and long-term investing principles.

Include appropriate investment risk disclosures where relevant.
